# 提交信息格式

## title 格式

`<type>: <描述>`（type 由前缀规范确定），言简意赅，≤40 字符，中文。

## description 格式

- 标题后空一行，再接 description。
- 详细说明改动内容，中文，Markdown 格式。代码符号、文件名不翻译。
- 不加 co-author、generated by 之类信息。

## 完整示例

```
feat: 新增 mermaid 图类型选择指南

- 步骤 2 将一行类型枚举替换为 15 行决策表，每种类型标注
  代码阅读和技术介绍场景下的具体触发条件。
- 步骤 5 大小控制从通用阈值改为按图类型差异化。
```
