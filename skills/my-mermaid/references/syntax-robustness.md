# 语法与显示鲁棒性规范（所有图类型必读）

生成任何 mermaid 代码前应用本规范；生成后按末节自查清单核对，命中即改。

## 强制引号

所有节点标签、边标签、subgraph 标题、别名/描述，**一律用双引号包裹**——不限于含空格或特殊字符时。引号是最低成本的语法保险：`@ ( ) [ ] { } : ; , .` 等符号只有在引号内才安全。

- 节点：`A["流程 @入口"]`
- 边标签：`A -->|"是"| B` 或 `A -- "标签" --> B`
- subgraph：`subgraph sg1["前端（Web）"]`
- 别名/描述式：`state "等待中" as waiting`、`participant FE as "前端"`

「边标签」指 flowchart 系的 `-- "文本" -->` / `-->|"文本"|` 写法。以下场景**无引号机制**（引号会按字面渲染进图里）：mindmap 节点文本；gantt/timeline/journey 的自由文本字段；state 图冒号后的转移标签与状态描述（`A --> B: 文本`、`id : 文本`）；sequence 图冒号后的消息文本。这些场景改为规避特殊字符，写法见对应类型文件。

## 引号内转义表

| 字符 | 写法 | 陷阱类型 |
|------|------|---------|
| `"` | `#quot;` | 语法：提前闭合字符串 |
| `#` | `#35;` | 语法：转义引导符 |
| `<` `>` | `&lt;` `&gt;` | 显示：被当 HTML 标签吞掉（如 `Vec<T>` 的 `<T>` 整段消失） |
| `&` | `&amp;` | 显示：HTML 实体引导符 |

## 保留字与 ID 陷阱

- 小写 `end` 作节点 ID 或裸文本会破坏 flowchart/subgraph/结构块——ID 改用 `End`、`finish` 等，文本放进引号标签。
- 边线后紧跟 `o`/`x` 开头的节点 ID（如 `A---oB`）会被解析为圆点/叉形线端——ID 避免以 `o`/`x` 开头，或在边线与 ID 间留空格。
- 节点/参与者/状态/subgraph 的 ID 只用 `[A-Za-z0-9_]`；中文与特殊字符一律进标签，不进 ID。

## 显示鲁棒性

- 换行一律 `<br/>`，禁用 `\n`（会渲染为字面量）。
- 除 `<br/>` 外禁用一切 HTML 标签（不同渲染器 securityLevel 不同，行为不可预期）。
- 长标签（超过约 14 个全角字符）用 `<br/>` 手动分行，控制节点宽度。
- 标签内不写 Markdown 语法（`**`、`` ` `` 等默认渲染为字面量）。

## 结构规则

- `%%` 注释独立成行，不追加在语句尾部。
- 声明与指令各自独立成行，顺序：frontmatter title → `%%{init}%%`（如有）→ 图类型声明。

## 生成后自查清单（命中即改）

- 还有未加引号的标签、边标签、subgraph 标题？
- 引号内残留裸 `"` `#` `<` `>` `&`？
- 残留 `\n`，或出现 `<br/>` 之外的 HTML 标签？
- 出现小写 `end`？边线后紧跟 `o`/`x` 开头的 ID？
- ID 里混入了中文或特殊字符？
