# Gantt / Timeline / Journey

## Gantt

功能开发排期、版本路线图、里程碑。**不适用代码阅读场景**。

```
gantt
  title 项目排期
  dateFormat YYYY-MM-DD
  axisFormat %m-%d
  section 基础功能
  需求评审  :done, a1, 2026-06-01, 3d
  开发      :active, a2, after a1, 5d
  测试      :a3, after a2, 2d
  section 性能优化
  压测评估  :b1, 2026-06-10, 2d
  优化实施  :b2, after b1, 3d
```

- `:done`（已完成，灰色）、`:active`（进行中，蓝色）、`:` 后无标记（待开始，白色）
- `after <id>` 相对日期引用；日期也可用绝对日期
- `section` 分组不同工作流
- 任务名/section 名为自由文本、无引号机制，**禁用半角 `:`**（冒号是字段分隔符，出现即语法错误），需要冒号语义时用全角"："
- 里程碑：`里程碑事件 :milestone, m1, 2026-06-15, 0d`

### 配色

gantt 自动着色，`section` 间自动分配不同颜色，不支持手动 classDef。

### 大小限制

超 15 条任务时提示精简或按 section 拆分。

## Timeline

技术演进史、版本变更年表、关键事件序列。

```
timeline
  title 项目演进史
  2025-Q3 : 项目立项
           : 技术选型完成
  2026-Q1 : 0.1.0 发布
           : hook 体系上线
  2026-Q2 : 0.2.0 发布
           : 插件生态完善
```

- `时间段 : 事件` 用冒号分隔
- 事件文本内避免再出现半角 `:`（会被当作分隔符），需要时用全角"："
- 同一时间段多个事件用缩进续行
- 自动按时间顺序排列

### 大小限制

超 15 个事件时提示精简。

---

## Journey

用户操作路径、体验流程、满意度打分。

```
journey
  title 用户首次使用流程
  section 访问
    打开页面: 4: 用户
    注册账号: 3: 用户
  section 使用
    创建项目: 5: 用户
    首次构建: 3: 用户
  section 反馈
    查看结果: 5: 用户
```

- 分数 1-5（1=差，3=中，5=好）
- `: 分数: 角色` 格式；步骤名内禁用半角 `:`（冒号是字段分隔符），需要时用全角"："
- `section` 分阶段

### 大小限制

超 10 个步骤时提示精简或按 section 拆分。
